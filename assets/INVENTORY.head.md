# assets/INVENTORY.md — every asset slot the reference renders

Generated by `node scripts/inventory.mjs && node scripts/write-inventory.mjs`. The tables
below are machine-written from `.harness/inventory.json`; **do not hand-edit them.** This
narrative is `assets/INVENTORY.head.md` and the font findings are `assets/INVENTORY.tail.md`.

Source data is the Prompt 1 capture: `.harness/assets/<page>.json` (slot geometry per
breakpoint) and `.harness/ref/<page>/1440/<section>.png` (dominant-colour sampling).
Nothing was re-fetched, and it could not have been — see the bot-wall note below.

## Provenance, per D-09 and D-11

- **TAKE** — generic UI icons and open-licensed fonts, verifiable in one step.
  **Zero slots qualified.** Every image on the reference is a photograph of their work,
  their logo, or a branded badge illustration. The only genuinely generic glyphs on the
  site are its two **icon fonts** (`elementskit`, `ElegantIcons`) and three Twemoji SVGs
  in the privacy policy — and per the Prompt 1 decision those are redrawn in
  `lucide-react` rather than lifted, because matching stroke width and box is what the
  clone is actually measuring. So the TAKE column is empty by outcome, not by omission.
- **REPLACE** — their photos, logo, wordmark, badge images, project shots.
  **Not one byte of these entered this repo, not even temporarily.** What crossed the line
  is a rendered width, a height, an `object-fit`, a border-radius, and a colour sampled
  from *our own* screenshot of the band.
- **DELETED** — inventoried because a generator would otherwise re-derive them from the
  layout, then deliberately left unfilled because the band they live in is not built.

## The reference is now behind a bot wall

Between Prompt 1 and this turn, `costarroofinginc.com` acquired a JS interstitial
("One moment, please…", 51 characters of body text, a 5-second self-reload). It does not
clear headless, and it did not clear headed with a real Chrome UA over eight 6-second
polls. `CLAUDE.md` pre-answered this exact branch: *one retry headed with a normal UA, then
fall back to a local saved copy.* Our local saved copy is the Prompt 1 capture, taken while
the site was still open. Recorded as **F-10** in `docs/known-divergence.md`.

Practical consequence for this file: **the geometry here is frozen and cannot be
re-measured.** Treat it as the specification, not as a snapshot to refresh.

## What the placeholders are

Flat-fill SVG at the slot's rendered dimensions and its sampled dominant colour, carrying
the slot ID and the pixel dimensions as text, with a hairline border so the box edge is
visible against a same-tone band. System font only. **No external placeholder service, no
network dependency, no runtime.** They are checked into `public/placeholders/`.

Two colours are honest but weak: where the Prompt 1 probe recorded `null` (the image had
not decoded when it ran), the fill falls back to the *average of the whole section*, which
on a mostly-white band comes back near-white. Those rows are tagged `section-average`
rather than `slot-crop` in the table so the difference is never silently merged. The border
and the label keep the box visible either way.
